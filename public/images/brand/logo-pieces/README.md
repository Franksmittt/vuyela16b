# Vuyela Group logo — unflattened pieces

Traced from the official light/dark logo plates into separate transparent PNGs.

All full-size pieces share the same canvas (`3576×1184`) so they stack 1:1.
`*-cropped.png` variants are tight bounds. `*-on-white.png` are QA previews.

6. `01-vuyela.png` — yellow wordmark + black outline
7. `07-group.png` — black GROUP (for light backgrounds)
8. `08-tagline.png` — black tagline (for light backgrounds)
